# Mi|Navee Firmware info

Unofficial research catalog of manufacturer CDN firmware links.

**Published surface (this repo only):** `index.html`, `static/` (incl. `themes/`), `lib/theme_consts.js`, `mi.json`, `navee.json`, and the thin Streamlit host `app.py`.

Themes (switcher above the page, or `?theme=`): **Noir** (`modern`), **Classic** (`classic`), **Showroom** (`fashion`).

This site does not host firmware binaries. Refresh tooling and local OTA mirrors live outside this repository and are not part of the public deploy.
